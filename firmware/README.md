# F2C23T-EN-V2.2.5.bin

## Changes

- Fixed PRM calculation

### Issues:

- Interference caused by LCD data transmission during FPGA acquisition is visible at timebase settings of 500, 200, 
  and 100 µs (test signal generated by Arduino: HIGH = 100.0000 µs, LOW = 3900.0000 µs, T = 4000.0000 µs, F = 250.00 Hz, Duty = 2.50%). 
  The developers introduced a delay between LCD data transmission and FPGA acquisition to prevent this interference from appearing on the screen.
  This interference is visible when moving the waveform using the MOVE function.
  The interference frequency is affected by the value stored in the XMC_EXT1 register (0xA0000220).

# F2C23T-EN-V2.2.0.bin

## Changes

- Implemented an FPGA-based hardware trigger for both channels, featuring 
  signal pre-trigger history and support for AUTO, NORMAL, SINGLE, RISE, and FALL modes.
  It can capture short single pulses (e.g., 125 ns at a timebase of up to 5 µs which is not possible in stock firmware).
- Fixed a display artifact affecting the MOVE and CURSOR menus when the signal generator is turned off.
